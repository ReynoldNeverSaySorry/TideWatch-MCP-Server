# Market Fusion Series

TideWatch Hackathon 视频的主概念图系列，将股票市场符号直接嵌入海潮世界。

| 文件 | 叙事含义 |
|---|---|
| `01-born-to-predict.png` | K 线从海面升起，TideWatch 的青色观察线诞生 |
| `02-bull-bear-conflict.png` | 红色牛势与绿色熊势相撞，系统拒绝忽略冲突 |
| `03-overconfidence-crash.png` | 看似冲天的高分结构在峰顶碎裂，揭示过度自信 |
| `04-choosing-wait.png` | 多空方向退到两侧，水平青线主动选择等待 |
| `05-taught-by-the-market.png` | 历史 K 线、回填结果和市场记忆汇成一条纪律 |

## 目录

- `source/`：`1536×1024` Dream Painter 原图。
- `16x9/`：`1920×1080` 视频剪辑图，默认使用。

提示词位于 `../../../prompts/market-fusion/`。第一张由 Natural Tide 母版转换，其余四张以第一张做图生图，以保持市场网格、海面和色彩一致。
