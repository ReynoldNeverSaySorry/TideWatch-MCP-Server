## 核心叙事

TideWatch 不是因为预测过一次正确结果而进化，而是因为它记录每次判断，在 5/10/20 个交易日后回填真实走势，再将错误沉淀为新的因子权重、信号阈值与行为护栏。

影片以市场作为老师，以四次真实策略升级作为成长节点：

1. **矛盾**：冲突信号且判断不强时，不交易。
2. **含糊**：弱多方向长期失效，不如保持观望。
3. **自信**：过度自信与方向翻转需要降置信度。
4. **诚实**：低置信度时不再硬给方向。

## 制作原则

- 故事先于功能，市场是老师，TideWatch 是学生。
- 真实 Dashboard、真实回填记录和真实规则优先于概念动画。
- 不承诺收益，不把历史胜率表述为未来保证。
- 不展示真实账户金额、API Key、访问码或未脱敏持仓。
- 海浪意象只用于章节转场，主体画面保持克制、可信、可验证。
